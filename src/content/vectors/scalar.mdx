# Stretching and reversing

You know how to add vectors. The other thing you'll do constantly: stretch them. *Three times this push.* *Half that velocity.*

Multiplying a vector by a number — a *scalar* — is exactly what it looks like. The arrow gets longer or shorter. Each component scales by the same factor.

Drag the slider on the left.

Try `k = 2`. The arrow doubles. Try `k = 0.5`. Halves. Try `k = 0`. It vanishes — where do you imagine it's gone? To a point at the origin. A vector with zero length and no defined direction. (The zero vector is a strange object. Useful, but strange.)

Now try `k = −1`. The arrow flips.

*Negative-one-times-an-arrow* sounds nonsensical until you watch it happen. Physically, it's the same push, reversed. The same velocity, in the opposite direction. The same step backward instead of forward.

This is the second move you can make with a vector. Add them; scale them. (Eventually, when we get to matrices, you'll be able to transform them in more ambitious ways.) For now, scale is the move.
