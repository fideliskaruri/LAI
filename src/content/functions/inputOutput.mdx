# A function is a machine

Forget the word *function* for a second. Picture a machine.

You feed it a number. It does whatever it does inside — whirring, clicking, fine — and it spits out exactly one number. Same input today, same input tomorrow: same output. The machine doesn't get moody. It doesn't change its mind.

That's a function.

The machine on the left has a very simple rule. *Take the input. Double it. Add one.* In math notation:

`f(x) = 2x + 1`

The little `f(x)` reads "f of x," and it means *the output of the machine f when you feed it x*. The letter `f` is just the name of the machine — we could have called it `Bartholomew` if we were feeling formal. Mathematicians settled on lowercase letters because they were tired of writing long words.

Drag the scrubber on the x-axis. Watch what happens.

The vermilion line on the canvas is the *graph* of the function — every possible input plotted against its output, all at once. The dashed L is the live correspondence: from input on the bottom, up to the line, across to output on the side. Same input, same output, every time. That's the rule.

Try `x = 0`. The machine gives you `1`. Try `x = 2`. It gives you `5`. Try `x = -1`. It gives you `-1`. (That last one always surprises me a little, even though I can see the algebra. Apparently `-2 + 1 = -1`. Apparently.)

A few things about this you should notice.

First: the graph is the *picture of every possible answer*, drawn before you asked anything. You're not generating it by dragging. You're just visiting it. The function existed already.

Second: every input has *exactly one* output. If a vertical line through your input ever hit two points on the curve, it wouldn't be a function — it'd be a multi-valued thing, and we'd have to argue about which output we meant. We don't allow that. One in, one out.

Third — and this is the one Galileo needed and didn't have: *position is a function of time*. The ball's distance down the ramp is some `f(t)`. If you knew `f`, you'd know where the ball was at every instant. The rest of this chapter is about getting from there to *how fast it's moving* at every instant.
